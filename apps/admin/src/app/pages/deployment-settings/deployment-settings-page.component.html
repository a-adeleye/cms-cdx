Production image storage

When publishing to production, any article cover image still pointing at local/dev storage is re-uploaded here and its URL rewritten. Leave blank to skip this step.

Published cover images are stored directly under the site blog path (for example, blog/cover.png). The API server resolves these environment variables only during a production build; the keys themselves are never stored in this CMS or sent to the browser.
